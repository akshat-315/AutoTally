⏺ Here's a quick overview of Claude Code plugins:

  Using Plugins

  Browse & manage plugins interactively:
  /plugin

  Install from the official marketplace:
  /plugin install plugin-name@claude-plugins-official

  Other commands:
  - /plugin disable name — disable a plugin
  - /plugin enable name — re-enable
  - /plugin uninstall name — remove
  - /reload-plugins — reload without restarting

  You already have two plugins enabled: swift-lsp and frontend-design from the
  official marketplace.

  What Plugins Can Provide

  - Skills — custom slash commands (e.g., /my-plugin:hello)
  - Agents — specialized subagents
  - Hooks — event handlers that run on tool calls
  - MCP servers — external tool integrations
  - LSP servers — language intelligence (diagnostics, go-to-definition)

  Creating Your Own Plugin

  1. Create a directory with .claude-plugin/plugin.json (manifest)
  2. Add skills/, agents/, hooks/, etc. as needed
  3. Test locally with claude --plugin-dir ./my-plugin

  Adding Custom Marketplaces

  /plugin marketplace add owner/repo          # GitHub repo
  /plugin marketplace add ./local/path        # Local directory

  The official marketplace includes integrations for GitHub, Slack, Figma,
  Sentry, Vercel, and many more. Run /plugin to browse what's available.
